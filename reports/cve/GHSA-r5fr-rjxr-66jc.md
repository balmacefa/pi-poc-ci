# CVE-2026-4800 (GHSA-r5fr-rjxr-66jc) Report

**Aliases**: CVE-2026-4800
**Severity**: HIGH
**Affected Package**: lodash, version 4.17.11 (affected range: >=4.0.0 <4.18.0)
**First Fixed Version**: 4.18.0

**How earlier CVEs were fixed in this repository**:
A previous CVE, CVE-2018-16487, was fixed by updating `lodash` from `4.17.4` to `4.17.11` in `targets/vuln-app/package.json` (commit `4f3aebb588204d3f9546288c57afe9103e2c7a89`). The fix involved a direct dependency version bump.

**Proposed Fix**: Update `lodash` to version `4.18.0` or higher.
